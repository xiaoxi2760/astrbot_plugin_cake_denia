## 一、设计说明

### 整体风格
粉白系梦幻卡片：彩色玻璃泡泡漂浮 + 白色圆角卡片 + 粉渐变投喂日方块。呼应达妮娅「泡影视阈」异能设定（虚质泡泡困敌于梦幻星穹）。

### 布局结构
```
┌──────────────────────────────┐
│   🍰 测试员的投喂日历  🍰     │  ← 标题（巧克力棕，两侧蛋糕emoji）
│          2026年8月            │  ← 副标题
│   一 二 三 四 五 六 日        │  ← 星期（周末粉红）
│  ┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐  │
│  │1 ││  ││3 ││  ││5 ││6 │  │  ← 日期方块（投喂日粉色渐变+🍰）
│  └──┘└──┘└──┘└──┘└──┘└──┘  │
│  ┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐  │
│  │  ││10││  ││12││  ││14│  │
│  └──┘└──┘└──┘└──┘└──┘└──┘  │
│  ……                          │
│  [本月投喂娅娅 11 天，共 16 块蛋糕] │  ← 页脚粉色胶囊
└──────────────────────────────┘
背景：粉渐变 + 彩色玻璃泡泡漂浮（10颗）
```

### 字体
CSS 字体栈：`Microsoft YaHei, PingFang SC, sans-serif`（服务器为 Windows 即微软雅黑）。
`🍰` 由系统 emoji 渲染（Chrome 内建彩色 emoji 字体）。

## 三、渲染方法

依赖：`playwright`（pip 一次安装即可），渲染走**系统 Chrome**（`channel='chrome'`），无需下载浏览器内核。

```bash
py -m pip install playwright          # 首次安装
py astrbot_plugin_cake_denia/design/make_calendar_html.py
```

输出到 `design/render_out/`（已在 .gitignore，不入库）。脚本支持多方案并存（DESIGNS 列表：A1 泡泡初绽 / A2 马卡龙双层 / A3 柔雾珠光 / A4 糖果彩带），改参数后重跑即可出新图。
